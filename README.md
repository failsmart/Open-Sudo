# Open-Sudo
Android GPG PGP SSH ECCD  .kdbx Manager open keychain alternative.

## Features 🏗️ (Todos)
- Generate, import, and manage PGP keys, including subkeys, revocation, and expiration.
- Generate and manage SSH keys, with support for Ed25519, ECDSA, and RSA fallback.
- Encrypt, decrypt, sign, and verify files, messages, and plain text.
- Integrate with `.kdbx` vaults by storing keys as protected attachments or fields, with autofill where possible.
- Search for keys locally, with optional keyserver lookup only after user consent.
- Protect keys with passphrases and biometrics, plus Android Keystore wrapping for added security.
- Provide basic SSH agent forwarding simulation or export support.
- Support backup and restore through encrypted exports.
